# Bundled Noto Sans fonts

These regular-weight Noto Sans fonts are bundled for PDF layout reconstruction.
The backend maps each target language to its script-specific font.

Sources:
- https://github.com/notofonts/noto-fonts
- https://notofonts.github.io/

Noto fonts are distributed under the SIL Open Font License. See the font metadata
and repository license for the exact licensing terms.
